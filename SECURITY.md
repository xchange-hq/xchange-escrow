# Security

If you find a way for escrowed funds to leave by any door other than a
release to a registered counterparty or a refund to the depositor, or any
other fault that could cost someone their funds, write to
**contact@xchangehq.com** before making it public. Say what you found and
how to reproduce it. You will get an answer within three days.

Please do not test against other people's escrows on mainnet. The tests in
`program/tests` run against a local validator.

The known limits of the design are in the README under "What you are
trusting".
